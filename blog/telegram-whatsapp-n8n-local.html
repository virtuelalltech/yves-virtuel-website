Utiliser Telegram avec n8n en local : guide complet

Connectez Telegram à votre instance n8n locale via ngrok : architecture, tunnel HTTPS, configuration des webhooks et premier workflow de test. Tout en images.

Au sommaire

  1. 🏛️ Architecture du système
  2. ⚙️ Configuration du tunnel ngrok

🏛️ Architecture du système

Pour faire communiquer Telegram avec votre instance n8n locale, il faut comprendre le flux de données. n8n tourne sur votre machine (localhost:5678), mais Telegram ne peut pas atteindre une adresse locale. Il nous faut un tunnel public HTTPS.

Flux global

1. L'utilisateur envoie un message sur Telegram

2. Telegram appelle votre webhook public (URL ngrok)

3. ngrok transmet la requête à votre n8n local (localhost:5678/webhook/...)

4. n8n exécute le workflow et répond

5. La réponse remonte jusqu'à Telegram → l'utilisateur

Point d'attention

L'URL ngrok change à chaque redémarrage (plan gratuit). Pour la production, utilisez un domaine personnalisé ngrok ou un VPS avec domaine fixe.

⚙️ Configuration du tunnel ngrok

Étape 1 : S'inscrire et installer ngrok

  1. Créez un compte sur ngrok.com
  2. Téléchargez ngrok pour votre OS (Windows / Mac / Linux)
  3. Dézippez et placez l'exécutable dans un dossier accessible (ex. C:\ngrok\)
  4. Authentifiez-vous : ngrok config add-authtoken VOTRE_TOKEN

Étape 2 : Lancer le tunnel

Ouvrez un terminal séparé de celui de n8n (ngrok doit tourner en continu) : 

ngrok http 5678

ngrok affiche deux URLs publiques (http + https). Copiez l'URL HTTPS (ex. https://abc123.ngrok-free.app).

Étape 3 : Configurer le webhook Telegram

  1. Créez un bot via @BotFather sur Telegram (/newbot)
  2. Récupérez le token du bot
  3. Définissez le webhook : ouvrez cette URL dans votre navigateur (remplacez VOTRE_TOKEN et VOTRE_URL_NGROK) : 
https://api.telegram.org/botVOTRE_TOKEN/setWebhook?url=https://VOTRE_URL_NGROK/webhook/telegram

Vous devriez voir {"ok":true,"result":true,"description":"Webhook was set"}.

Étape 4 : Créer le workflow n8n

  1. Dans n8n : Webhook node → Path : telegram → Method : POST
  2. Ajoutez un node Telegram (ou Send Message) : connectez votre credential bot (le token BotFather)
  3. Dans Chat ID : {{ $json.message.chat.id }}
  4. Dans Text : Message reçu : {{ $json.message.text }}
  5. Reliez Webhook → Telegram
  6. Cliquez Execute Workflow (ou activez-le en production)

Test

Envoyez un message à votre bot sur Telegram. Si tout est bon, il vous répond avec le texte reçu. Voilà ! 🎉

Variables d'environnement utiles (optionnel)

Pour éviter de recopier l'URL ngrok partout, créez un fichier .env à la racine de n8n :

WEBHOOK_URL=https://VOTRE_URL_NGROK/webhook/telegram

Puis dans vos nodes : {{ $env.WEBHOOK_URL }}.
