DockFlow

Extraction intelligente de commandes portuaires reçues par e-mail, transformées en données JSON structurées et validées.

PythonFastAPIPydanticPydanticAI

Contexte

Une entreprise de manutention portuaire (acconier) reçoit ses commandes de dockers par e-mail : nombre de personnes par métier, équipes de jour ou de nuit, durée, client.

Le problème

Ces informations sont écrites en texte libre et doivent être relues puis ressaisies à la main.

L'objectif

Transformer chaque e-mail en données structurées et vérifiées, utilisables ensuite dans un système de gestion.

L'approche technique

Un agent d'extraction (PydanticAI) lit le texte de l'e-mail. Les données sont validées par des modèles Pydantic puis par des règles métier, et exposées par une API FastAPI. Règle prévue : si la validation échoue, le cas est envoyé à une personne pour relecture.

Fonctionnalités réellement développées

  • Extraction testée sur un lot d'e-mails d'essai
  • Validation des données avec des modèles typés
  • Import de données fictives dans un Odoo 19 de test

Résultats observés

Les résultats de l'extraction sur les e-mails d'essai sont en cours d'analyse. Aucun taux de réussite n'est publié à ce stade.

Limites actuelles

  • Projet en développement, non déployé.
  • Testé sur des e-mails d'essai, pas sur des commandes réelles.
  • Aucun client payant confirmé à ce jour.
  • L'intégration Odoo n'est pas réalisée : seul un environnement de test existe.

Prochaines étapes

  • Analyser et documenter les résultats de l'extraction.
  • Brancher la réception des e-mails via n8n.
  • Intégrer les données validées dans Odoo.

Aucune capture ni démonstration publique n'est affichée pour l'instant. Une démonstration peut être présentée sur demande.
